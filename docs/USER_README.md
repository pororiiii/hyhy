# 처음 쓰는 사람을 위한 사용법

담당 AI가 실제로 만든 도구와 확인한 실행 결과를 바탕으로 이 문서를 작성해. `____`는 실제 내용을 적을 자리야. 처음 사용하는 사람이 이 문서만 보고 따라 할 수 있도록 적어.

모르는 내용은 ‘미확인’, 이번 도구와 관련 없는 항목은 ‘해당 없음’으로 표시해. 실제로 없는 기능이나 승인 절차를 만들어 적지 마.

## 무엇을 도와주나요

- 누구의 어떤 일을 줄여 주나요: ____
- 도구가 하는 일 / 사람이 결정하는 일: ____ / ____

## 실행법

1. 필요한 환경과 준비할 자료: ____
2. 터미널(명령을 입력하는 창)에 칠 명령: `____`
3. 열 주소 또는 확인할 결과 파일: ____
4. 정상 실행되면 보이는 것: ____
5. 종료·재시작 방법과 데이터 저장 위치: ____

## 사용법

1. 이 형식으로 입력해요: ____
2. 이 버튼 또는 명령을 실행해요: ____
3. 결과 ____를 확인해요. 승인 절차가 있는 도구라면 승인 대기 결과를 누가 확인하는지도 적어요: ____

## 잘 안 될 때

해당하는 오류에 대해 기록해요.

- 빈 입력·잘못된 형식: 확인할 것 ____ / 복구 방법 ____
- 중복·외부 서비스 실패: 확인할 것 ____ / 복구 방법 ____

## 테스트와 못 한 것

- 테스트 명령: `____`
- 마지막 확인: 입력 ____ / 기대값 ____ / 실제 출력 ____ / 시각 ____
- 못 한 것과 이유: ____
- 한계·사람이 다시 확인할 일: ____
- 유지 담당 역할과 다음 개선: ____
